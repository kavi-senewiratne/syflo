Basic — blaue Frage-Blase, graue Antwort-Fläche

Heute trägt in Basic nur die Frage eine Fläche (grau, bg-gray-100) samt Cartoon-Schatten; die Antwort steht ohne Fläche direkt auf Weiß. Die vier anderen Themes geben beiden Seiten eine Fläche — Basic ist das einzige Theme ohne diese Regel.

Drei Varianten, wie Basic nachzieht. Gleicher Inhalt in jeder Spalte: eine Frage mit Zitat, eine Antwort mit Markierung, Formel und Branch-Link.

Was in jeder Variante gleich mitentschieden wird

  • Reichweite: Die Regel käme als :root[data-theme='professional']-Block in index.css — genau die Form, die die vier anderen Themes schon haben. Nur Basic ändert sich, die anderen Themes bleiben unberührt.
  • Zitat in der Frage: bleibt currentColor mit 75 % Deckkraft. Auf Blau (A, C) wird es dadurch automatisch hellblau-weiß statt grau.
  • Markierungen: die fünf Highlight-Pastelltöne sind Produktkonstanten und ändern sich nicht. Auf grauem Antwortgrund (A, C) sitzen sie sichtbar; auf Blau kämen sie nur vor, wenn eine Frage markiert wird — dort bleiben sie unverändert pastell auf Blau.
  • Antwort-Padding: eine Fläche braucht Innenabstand (10–12 px), sonst klebt der Text am Rand. Damit rückt der Antworttext um dieselbe Strecke nach rechts wie in den anderen Themes.
