Structure the information in this video.
1 · What an LLM actually is 00:00
  • An LLM is two files: the parameters (140 GB for Llama-2-70B) and ~500 lines of run code.
  • Training compresses ~10 TB of internet text into the parameters — like a lossy zip of the internet.
2 · Training pipeline 14:14
  • Pre-training: predict the next word on internet text — expensive, rare (~1×/year).
  • Fine-tuning: swap the dataset for hand-written Q&A — cheap, weekly; this creates the assistant.
  • Optional RLHF: comparison labels are easier for humans than writing answers.
3 · Scaling laws & tool use 25:43
  • Accuracy improves predictably with more parameters + more data — no sign of topping out.
  • Modern assistants delegate: browser, calculator, code interpreter, image generation.
4 · Security: jailbreaks, injections, poisoning 45:30
  • Jailbreaks via roleplay or base64; prompt injection hides instructions in web pages or images.
  • Data poisoning: trigger words planted in training data can flip behavior.
