Feedback feature — entry points & send dialog

Two ways in: a pinned icon in the sidebar (collapsed rail and expanded), and a /feedback composer command in any chat. Both open the same dialog. Text only, no attachments — sending goes to a private inbox (email), never a public GitHub issue directly (ADR-0010).

1 ENTRY POINT — collapsed rail
Feedback icon sits directly above the Settings gear at the bottom of the rail — same tier as the app's other persistent utilities, not mixed in with chat rows.

2 ENTRY POINT — /feedback in the composer
/feedback is a pure trigger, not a shorthand with arguments — it opens the identical dialog from section 3 below, Bug/Idea/Question chip included, where the kind is picked with a click same as from the sidebar button. Typing / at the start of an empty composer opens a command menu (today just this one entry). Any text already typed after /feedback  carries over as the dialog's starting text instead of being discarded. The composer itself is left untouched — no message gets sent.
