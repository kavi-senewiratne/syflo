# Matrix theme — Textlesbarkeit

Ursache: Im Matrix-Theme lädt die App IBM Plex Mono nur in 400/500/600 (main.tsx) — Tailwinds font-bold verlangt 700, das es nicht gibt, also matcht der Browser auf 600. Bei einer Monospace-Schrift mit ohnehin dicken Strichen ist der Unterschied zwischen 400 und 600 kaum sichtbar. Die Display-Schrift Share Tech Mono hat sogar nur einen einzigen Schnitt (400) — dort ist "fett" technisch gar nicht vorhanden.

Sechs Varianten unten, gleicher Beispieltext, jeweils mit denselben Farben aus dem echten Matrix-Theme. D/E/F bauen auf C auf (Helligkeits-Hierarchie + Phosphor-Glow) und probieren je einen zusätzlichen Verstärker aus.

A — Baseline (aktueller Zustand)
Nur Font-Weight als Unterscheidungsmerkmal. Überschrift, Fließtext und "fett" markierter Text laufen optisch ineinander.

B — Helligkeits-Hierarchie (Phosphor-Ramp)
Statt auf Font-Weight zu setzen (der im Terminal-Font kaum wirkt), nutzt jede Ebene einen anderen Helligkeitswert derselben Grün-Rampe, die im Matrix-Theme ohnehin schon definiert ist (gray-500 → gray-700 → gray-950 → accent). Passt zum Terminal-Charakter: heller = wichtiger.

C — Helligkeits-Hierarchie + Phosphor-Glow
Wie B, aber Überschriften und fett markierter Text bekommen zusätzlich den sanften Glow-Effekt, den das Matrix-Theme an anderer Stelle schon für Akzentflächen nutzt (--syflo-shadow-ink / phosphor-glow). Macht Hervorhebungen noch klarer, ohne knallig zu wirken.

D — C + Unterstrich am fetten Text
Wie C, aber fett markierter Text bekommt zusätzlich eine dünne Unterstreichung (underline). Das ist ein Signal, das NICHT von Farbe/Helligkeit abhängt — hilft z. B. bei Rot-Grün-Sehschwäche (color blindness) oder auf schlechten Bildschirmen, wo der Glow kaum zu sehen ist.

E — C + dezente Hervorhebungs-Box hinter fettem Text
Wie C, aber statt (oder zusätzlich zu) Glow bekommt fetter Text eine sehr dezente Hintergrund-Box (highlight chip) in Akzentfarbe — ähnlich wie ein Textmarker. Springt am stärksten ins Auge, auch beim schnellen Überfliegen (skimming).

F — C + Klammer-Style für Überschriften
Wie C, aber Überschriften bekommen zusätzlich eckige Klammern ([ … ]) und die Caption ein >-Prompt-Zeichen — beides typische Terminal-Konventionen. Verstärkt die Unterscheidung zwischen Überschrift und Fließtext durch Form, nicht nur durch Farbe.
